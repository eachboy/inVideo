# БД, SQLAlchemy 2.0, Alembic (источник: architecture.md 3.3, quality.md)

## Модели
- Типизированные модели: `Mapped[...]` и `mapped_column`. Время — с часовым поясом, в UTC. PK — BIGINT identity; публичный идентификатор (11 символов) — отдельное уникальное поле.
- Соглашение об именах ограничений задано в metadata (`ix_`, `uq_`, `ck_`, `fk_`, `pk_`); без причины вручную имена не задавать.
- Статусы, видимость, роли — VARCHAR + CHECK, значения описаны Python-enum. Нативный PostgreSQL ENUM не использовать.
- Счётчики: BIGINT, по умолчанию 0, CHECK не меньше нуля.
- Связи: `lazy="raise"`. Подгрузка только явная в репозитории: пакетная для коллекций, JOIN для «один к одному». N+1 — баг.

## Репозиторий
- Методы с говорящими именами («лента подписок после курсора»). Не коммитит, не проверяет права.
- Пагинация keyset по паре «значение сортировки + id». OFFSET только для релевантности и не глубже 500.
- Счётчик меняется выражением в UPDATE («значение плюс 1»), и только если строка реально вставлена или удалена (проверка rowcount).
- Гонки: вставка с игнорированием конфликта и проверкой rowcount; блокировка строки (`FOR UPDATE`) при смене реакции и изменении порядка плейлиста.
- Индекс проектируется под конкретный запрос. У частичного индекса условие запроса должно совпадать с предикатом, иначе индекс не используется. Каждый новый запрос — `EXPLAIN ANALYZE` на данных из `scripts/seed_data.py`.

## Сессии
- API: async, `expire_on_commit=False`. Воркеры: sync. Суммарные пулы меньше лимита соединений PostgreSQL.

## Alembic
- Одна миграция — одно логическое изменение, понятное имя. Автогенерация — только черновик: индексы, триггеры и расширения она не видит или видит неточно.
- Триггер `search_vector` и расширение `pg_trgm` пишутся в миграции вручную.
- Применённые миграции не редактировать — только новая. У каждой есть откат. Миграции данных отдельно от миграций схемы.
- Обратная совместимость на время деплоя: сначала добавить, выкатить код, потом удалить старое.
- `env.py` импортирует все модели; автогенерация на неизменённых моделях даёт пустой результат.
