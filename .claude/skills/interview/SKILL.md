Проведи тренировочное собеседование по теме «$ARGUMENTS» для позиции Junior Python Backend / DevOps.

Правила:
1. Задавай **один вопрос за раз** и жди моего ответа. Начни с простого и усложняй: «что это» → «почему так» → «что если сломается» → «как масштабировать».
2. Вопросы строй по реальному коду и документам проекта (`docs/project/`), а не абстрактно.
3. После ответа: оцени (верно / частично / неверно), покажи, чего не хватило, дай эталонный короткий ответ. Только потом следующий вопрос.
4. Не подсказывай ответ в самом вопросе. Если я говорю «не знаю» — объясни и вернись к теме позже.
5. После 8–10 вопросов подведи итог: сильные места, слабые темы, что перечитать.
